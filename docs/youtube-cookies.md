# Персональные cookies YouTube — инструкция для пользователя

SkyFi играет YouTube-видео через собственный сервер в Нидерландах
(туннель). У дата-центровых IP плохая репутация у YouTube: без
cookies запросы быстро упираются в экран «Sign in to confirm
you're not a bot», а качество потоков падает до 360p. Личный
Netscape-файл cookies с youtube.com решает обе проблемы.

Привязка **добровольная**: без файла запросы к YouTube идут
вообще без куки — потолок качества 360p и высокий шанс
«Sign in to confirm you're not a bot» на каждом ролике.

## Шаг 1. Запасной аккаунт

Используйте **отдельный запасной аккаунт Google, не основной**.
Cookies — это ключи от аккаунта: теоретически их могут
скомпрометировать вместе с сервером, а YouTube может забанить
аккаунт за запросы с дата-центрового IP. Основным лучше не
рисковать. Достаточно бесплатного аккаунта без подписки
YouTube Premium.

## Шаг 2. Экспорт файла

1. Установите расширение **«Get cookies.txt LOCALLY»**
   (Chrome / Firefox, open-source).
2. Войдите на **youtube.com** под запасным аккаунтом
   (просто откройте главную — этого достаточно, видео смотреть
   не нужно).
3. Нажмите на иконку расширения → **Export** →
   **Export As...** → выберите формат **Netscape** и
   сохраните файл `cookies.txt`.

Проверка файла: первые строки должны быть
`# Netscape HTTP Cookie File`, внутри — строки с доменом
`.youtube.com`. Размер — обычно 10–60 КБ.

## Шаг 3. Загрузка в SkyFi

```
GET    /api/v1/skyfy/videos/youtube-cookies          → статус привязки
POST   /api/v1/skyfy/videos/youtube-cookies          → загрузить/заменить
DELETE /api/v1/skyfy/videos/youtube-cookies          → отвязать
```

Загрузка — multipart, поле `cookies`, файл как есть:

```bash
curl -X POST \
  -H "Authorization: Bearer <token>" \
  -F "cookies=@/path/to/cookies.txt" \
  https://<хост>/api/v1/skyfy/videos/youtube-cookies
```

Ответ `201` — файл привязан. Невалидный файл (не Netscape-экспорт
youtube.com) отклоняется с `422`.

Файл можно перезагрузить в любой момент — например, раз в
несколько недель свежим экспортом (сессионные куки протухают,
YouTube их ротирует; свежий файл = стабильнее работа).

## Что происходит с файлом

- Хранится в базе SkyFi **в зашифрованном виде** (ключ —
  `APP_KEY` сервера), в открытом виде нигде не сохраняется.
- Подставляется в YouTube-запросы именно вашего аккаунта
  (поиск в режиме видео, резолв «трек → видео», потоки).
- В сервис YouTube передаётся по внутренней сети и там
  существует только во временном файле.
- Удаление эндпоинтом стирает файл из базы сразу и полностью.

## Честные оговорки

- Это **arms race**, а не гарантия: YouTube может усилить
  проверки (следующий эшелон — PO-токены, пока не реализован).
  Если какое-то видео не открывается с `502` — попробуйте
  другое или обновите файл cookies.
- Антибот YouTube разный для разных роликов: официальные клипы
  крупных лейблов (VEVO) защищены сильнее обычных видео.
- Файл видят только сервера SkyFi. Всё равно держите на
  запасном аккаунте — параноидальный сценарий компрометации
  никогда не исключён полностью.
