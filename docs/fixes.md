# SkyFi Frontend — список правок макета (на моках)

Живой чек-лист правок по макету. Всё сверяем с китом
(`design/kit/index.html`, стили — `src/styles/kit.css`, источник —
`design/shared/kit.css`). Компоненты — по конвенции §2.1 `frontend.md`
(папка = `X.vue` + `X.ts` + `X.css`). Правим код → отмечаем здесь →
при необходимости обновляем `docs/status.md`.

Всё непродуманное, неотвеченные вопросы и недоработки фиксируем в
`docs/unthoughtout.md` (правило дрейфа: заметил → записал). Правка
относится к этапу интеграции с API (реальные запросы, сокеты,
локальная БД) — пропускаем и помечаем здесь `[api]`.

Легенда: `[ ]` не взято · `[~]` в работе · `[x]` готово · `[api]` этап
интеграции с API
