# SkyFi Frontend — статус: что есть / чего нет

Живой трекер пробелов между контрактом (`api.md`, `contracts.md`,
`frontend.md`, `video.md`) и текущим кодом (`src/`). Все приложение
сейчас работает на моках: ни одного реального запроса к бэку,
ни сокетов, ни аудио/видео-движка.

Легенда: ✅ есть · 🟡 мок/частично · ❌ нет

## 1. Инфраструктурные слои

| Слой | Статус | Комментарий |
|---|---|---|
| `types/` (снапшоты, enum) | ✅ | Скопированы из contracts.md |

## 3. Плеер (ядро, §5 frontend.md)

| Возможность | Статус | Комментарий |
|---|---|---|
| Сервер как источник истины (`GET /player`, version) | ❌ | Стор — локальная копия мока |
| Команды play/pause/seek/options с эхо-полями | ❌ | Все действия локальные |
| Контекст воспроизведения (play_source, курсор) | 🟡 | `playSnapshot` ставит `single`; контекстов favorites/playlist/wave нет |
| Виртуальный поток (история + текущий + очередь + остаток) | 🟡 | Очередь есть (мок), истории и точки возврата нет |
| Схема next/prev (очередь → контекст → repeat → избранное) | 🟡 | Упрощённо: next = первая в очереди, иначе цикл по избранному; prev с рестартом <3с есть |
| Shuffle (перемешанная копия, курсор вокруг текущего) | ❌ | Только флажок |
| Кросс-девайс (пульт, activate, presence) | ❌ | `activateDevice` только переключает флажок в моке |
| Применение состояния (команда → сокет → reconnect) | ❌ | |
| Очередь: add/remove/reorder по API, статусы pending/played | 🟡 | add/remove/reorder по `/player/queue` живые (стор на `QueueItem[]`, удаление/сортировка в плеере); потребление при воспроизведении и статусы — со стадией плеера |
| Now-playing: обложка/лирика/очередь/свайпы | 🟡 | UI готов (слои now/queue/lyrics), лирика по `/audio/lyrics` (подсветка по таймкодам, без таймкодов — просто текст) |
| Мини-плеер | 🟡 | Есть, но прогресс захардкожен 38% |

## 7. Предлагаемый порядок работ

1. **Фундамент**: `api/`-клиент (обёртка, ошибки, троттлинг-тосты), токен/сессия, регистрация устройства, Echo-клиент с эхо-глушением.
2. **Авторизация по API** + QR-флоу (обе стороны).
3. **Плеер-ядро**: аудио-движок, контексты и схема воспроизведения, серверная очередь, кросс-девайс, MediaSession.
4. **Поиск + детали сущностей**.
5. **Медиатека**: избранное (лайки/сорт), плейлисты CRUD, загрузки.
6. **Друзья + шары + уведомления**.
7. **Видео-режим**.
8. **Офлайн + скачивание + предзагрузка**.
9. **TV/car**: D-pad-фокус, QR-вход, профили адаптива.
10. Параллельно: приведение файлов к конвенции §2.1, тесты, недостающие макеты.

Правило обновления: правим код → правим этот файл. Сначала `api.md`,
потом `contracts.md`, потом код, потом статус здесь.
